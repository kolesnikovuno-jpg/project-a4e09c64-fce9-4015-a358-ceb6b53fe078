Garden Menu — навигационное SVG-меню на странице /garden.

Композиция: вертикальные стебли с горизонтальными ветками, на концах — кружки-кнопки (buds).
Кружки бывают: outline, filled, hatched.

Нумерация: стебли слева направо 01–06, ветки на стебле — 01.1, 02.1 и т.д.
Верхний кружок стебля = основной ID стебля.

Текущие ссылки:
- 05 (верхний кружок стебля 05) → /lyra

Адаптивность:
- Desktop (viewBox 900×600): оригинальные пропорции, мелкие кружки (r 6–15)
- Mobile (viewBox 800×600): увеличенные кружки (r 11–22), более высокие стебли

Стебли и линия земли — строго вертикальные/горизонтальные, тонкие (strokeWidth 0.8).
Цвет: hsl(168 40% 52%) линии, hsl(168 40% 72%) заливка/штриховка.
