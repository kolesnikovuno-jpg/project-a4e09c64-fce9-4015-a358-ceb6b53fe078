URL: /en/..., /ru/..., /uk/... (UI label "UA" for /uk).
Root /  → /en (default). Bare /about, /pricing, /lyra, /garden, /gateway, /unostudio → /en/<page>.
EN = source of truth. Edit EN first in src/i18n/dictionary.ts, then mirror RU + UK.
Hook: useLocale() from @/i18n/useLocale → { locale, t, switchTo, localePath }.
Always use localePath() when navigating between localized pages (preserves locale).
Switcher: <LanguageSwitcher background={...} hidden={...} /> — fixed top-center, square, expands down.
Rule: do NOT show switcher on hero screens or while a popup/modal is open. Pass hidden={...}.
Routes wired in App.tsx — generated from LOCALES × localizedPages array.
SEO: SEO component accepts `alternates` for hreflang. Static OG HTML emitted per locale via vite-plugin-og-pages.
Localized pages: Index, Lyra, About, Pricing, Garden, Gateway, UnoStudio, NotFound, LyraInfo panel.
Non-localized: /doodle, /pixels, /unocalc, /lyra-concept (utility / canvas pages).
