---
name: Garden numbering convention
description: Numbering rules for stems, buds and rings on /garden page
type: preference
---
Стебли на /garden нумеруются слева направо: 01, 02, 03, 04, 05, 06.

Кружки на стебле нумеруются сверху вниз, начиная с верхнего:
- {N}.1 — самый верхний кружок (вершина стебля)
- {N}.2 — следующий вниз
- {N}.3 — ещё ниже, и т.д.

Дополнительные элементы (кольца/окружности) вокруг кружка нумеруются ещё одним уровнем:
- {N}.{M}.1 — первое кольцо вокруг кружка {N}.{M}
- {N}.{M}.2 — второе кольцо, и т.д.

Примеры:
- 05.1 = вершина 5-го стебля
- 05.2 = ветка ниже вершины
- 05.1.1 = кольцо вокруг вершины 5-го стебля
- 05.2.1 = кольцо вокруг ветки 05.2

**How to apply:** В коде `src/pages/Garden.tsx` сейчас `stem.id` = вершина, `${stem.id}.${i+1}` = ветки. При работе с пользовательскими номерами мапить: {N}.1 → вершина стебля, {N}.2/{N}.3 → ветки сверху вниз; {N}.{M}.K → дополнительная окружность вокруг соответствующего кружка. Убедиться, что массив branches отсортирован по убыванию y от земли (сверху вниз по экрану).
