# Kolesnikov Studio — сайт и EGG

Один репозиторий кода, два действующих маршрута в **одном Vercel-проекте**:

| Контур | Канонический домен | Ветка |
|---|---|---|
| Сайт студии | https://www.kolesnikov.studio | `main` (production) |
| EGG Engine | https://egg.kolesnikov.studio | `integration/egg-unified-2026-11-12` (закреплённый доменный alias) |

## Вход в EGG с сайта студии

Главная сайта → EGG → `/{locale}/egg` → простой парольный экран
`src/pages/EggGate.tsx` → https://egg.kolesnikov.studio/egg/connect →
авторизация EGG (Supabase, если нет текущей сессии) → выбор проекта.

**Важно:** пароль сайта — только удобный предварительный экран; он расположен в
клиентском коде и **не является настоящей защитой**. Доступ к данным проектов
EGG обеспечивается отдельной авторизацией Supabase.

Если в исходной ссылке был `?project=UUID`, после входа сохраняется ссылка
на соответствующий проект. Старый компонент `UnoCalcEgg` больше не вызывается
из сайта студии как EGG. `/unocalc` остаётся самостоятельным инструментом.

## Единая линия EGG

- Рабочая ветка приложения: `integration/egg-unified-2026-11-12`.
- Технический якорь: `EGG_PROJECT_ANCHOR.md` в рабочей ветке.
- Архитектурная память: https://github.com/kolesnikovuno-jpg/EGG-Architecture
- История версий и старые feature/prototype-ветки не являются точками входа.
  Не удалять ветки, пользовательские проекты, фото, хранилище или БД без
  инвентаризации и отдельного решения.
- После изменений проверять Vercel READY **и** доменные alias; сборка сама по себе
  не доказывает функциональность полного EGG-цикла.

EGG — формирование идей и объектов через Поле, Материальное, Авторскую вертикаль,
восемь сфер, центральный синтез Желтка и явные решения Автора.
