# 02 — Visual Chord Sheet Canon

## 1. Core visual identity

SRA Visual Composer produces prompts for two related visual outputs:

1. **Abstract SRA Field Image**
   - abstract visualization of a person's base chord / inner field;
   - no room, object, face, landscape, mystical diagram, or literal element symbols.

2. **Visual Chord Sheet / Resonance Sheet**
   - a fixed sheet vessel containing field + spectrum + relationship;
   - a stable visual format for comparing different SRA readings.

The visual language is:

```text
restrained / minimal / architectural / semantic / airy / off-white / watercolor field + precise structural overlay
```

## 2. Fixed Visual Chord Sheet vessel

The Visual Chord Sheet should be treated as a fixed vessel.

Recommended layout:

```text
canvas: airy off-white / warm white background
upper zone: main living field, approximately 75–80% of the sheet
lower zone: flat proportional palette chord strip, approximately 8–12% of the sheet
margins: generous negative space
state: still, settled, readable
```

The image must communicate the structure of the chord, not dramatic motion or decorative beauty.

## 3. Main field

The upper field is one continuous watercolor-like semantic field.

Characteristics:

- translucent washes;
- soft organic edges;
- layered transparency;
- interpenetrating colour registers;
- no hard isolated patches;
- no separate symbolic objects;
- no terrain map;
- no landscape horizon;
- no node-link network.

Elemental masses should behave as field forces, not as literal things.

## 4. Bottom palette chord strip

The bottom strip is a visible proportional palette chord.

Rules:

- horizontal rectangular colour segments;
- proportions follow element balance or provided chord percentages;
- flat and readable;
- not decorative;
- not a legend with labels unless explicitly requested;
- should stay visually calm and integrated.

If exact proportions are not provided, the GPT may describe approximate qualitative proportions, but must mark them as non-calculated.

## 5. Structural overlay

The overlay should be architectural and precise, not mystical.

Allowed overlay elements:

- thin grey construction lines;
- subtle arcs;
- cross-hair nodes;
- contour traces;
- sparse measurement points;
- delicate trajectory curves;
- soft vertical/horizontal guide lines;
- quiet topology contours.

The overlay should clarify relationships, rhythm, spacing, and pressure. It must not dominate the field.

## 6. Element-to-field translation

### Wood

Visual behaviour:

```text
widening low-pressure growth field, upward opening, vertical emergence, living form-generating axis
```

Avoid literal trees, branches, leaves, forests.

### Fire

Visual behaviour:

```text
quickened rhythm, restrained intensity lift, manifestation accent, localized warmth or current-year modulation
```

Avoid flames, blazing suns, dramatic red-orange dominance.

### Earth

Visual behaviour:

```text
settled density, holding basin, accumulation, slow weight, grounding mass
```

Avoid literal soil, mountains, terrain, rocks.

### Metal

Visual behaviour:

```text
contour, spacing, precision, boundary, contraction rhythm, structural clarity
```

Avoid coins, weapons, machinery, shiny metallic objects.

### Water

Visual behaviour:

```text
depth field, inward/downward support, recovery, quiet flow, cool low-pressure distribution
```

Avoid waves, rivers, oceans, rain, liquid realism.

## 7. Palette logic

Suggested restrained palette family:

- Wood: muted sage, structural green, grey-green;
- Fire: soft terracotta, amber, coral, restrained warm accent;
- Earth: warm sand, ochre, clay, beige density;
- Metal: mineral grey, silver-grey, cool graphite linework;
- Water: deep blue-grey, teal-blue, indigo, cool depth.

The palette must remain low-noise, refined, calm, and architectural.

No saturated mystical neon, no fantasy glow, no psychedelic gradients.

## 8. Readability priority

The result should feel like:

```text
semantic field sheet
architectural resonance map
visual chord notation
structural atmosphere study
```

It should not feel like:

```text
fantasy art
chakra/aura image
landscape painting
interior rendering
startup dashboard
scientific chart
node-link graph
esoteric symbol map
```

## 9. Prompt composition style

Final prompts should be written in English for image generation reliability, unless explicitly requested otherwise.

They should specify:

- output type;
- fixed vessel/layout;
- field behaviour;
- element proportions;
- structural overlay;
- palette;
- atmosphere;
- forbidden visualizations.

The final prompt must be usable directly in an image-generation chat.
