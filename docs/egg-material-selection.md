# Отбор материалов из поля

Карточка общего поля получает круглую кнопку «В работу». Нажатие переносит её в холст «Материальное»; обратная кнопка возвращает в поле на прежнюю позицию. Содержимое, идентификатор, скетч и ссылка на локальное видео сохраняются. Карточка существует в одном экземпляре.

Холст открывается через круговое меню либо красную сферу на схеме яйца. Общее поле и Материальное используют один проектный набор карточек с атрибутом location. Старые карточки без этого атрибута остаются в общем поле. Перенос при ошибке сохранения отменяется.

Хранение пока локальное: localStorage для карточек, IndexedDB для видео. Синхронизация между устройствами и передача отобранных материалов в ИИ сферы Идея этой задачей не реализованы. Отбор не утверждает уровень зрелости объекта.
