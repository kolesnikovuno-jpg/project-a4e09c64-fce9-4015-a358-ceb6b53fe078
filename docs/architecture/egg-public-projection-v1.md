# EGG → Studio: public projection v1 (author approved 2026-11-25)

The public page is a projection of the accepted results of the egg, not a separate manual design process. The universal three-screen invariant is Presence → Disclosure → Interaction. No fourth screen required. Categories and size do not determine eligibility for publication.

## Contract
Stage: idea → concept → project → prototype → object. Stage informs presentation, never automatically promises availability. The author controls publication; only explicitly accepted, public results may be exported. The approved revision is a separate allowlisted snapshot. Internal deliberation, costs, credentials, contact data, and private documents are never exported. Publication must be authenticated, versioned, auditable and reversible; use a higher revision when rolling back. All three locales must be complete.

Design provides visuals, production/assembly provide approved characteristics, law/commercial provide approved terms, retail composes public presentation. Signals from Studio/Butler (questions, consented requests and anonymous aggregate analytics) return to the matching project; never automatically change the public snapshot or initiate spending.

## First pilot: Lyra
Website adapter reads /publications/lyra.json (same origin) and checks a strict schema. Existing page and sales funnel remain the fallback when no snapshot exists. The existing photo → interactive 3D → text sequence remains; first screen caption, second screen detail line, third screen description/action can be supplied in uk/ru/en. Interaction is explicitly none/collaboration/request; request is allowed only at object level. Current media and existing AR/color controls remain unchanged in v1. Non-commercial legacy route remains unchanged.
