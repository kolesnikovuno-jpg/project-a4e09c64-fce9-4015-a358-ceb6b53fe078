# EGG · First live Idea sphere ↔ ChatGPT pilot

Дата: 2026-11-04. Ветка `prototype/chat-ai-handoff`, только preview, без продвижения в production.

## Пользовательский путь

1. Автор открывает авторизованный EGG проект, сферу «Идея». Может войти в проект с `/egg?project=<uuid>&start=idea`.
2. В сфере есть кнопка «Переключиться на ChatGPT». Она открывает ChatGPT в новой вкладке и пытается скопировать **контекст проекта** (ID, ревизия, стадия, исходный замысел, принятая и обсуждаемая версии, вопросы и возвратная ссылка).
3. Если iPad/Safari не дал доступ к буферу, в раскрывающемся поле виден весь контекст для выделения и ручного копирования. Никаких токенов/секретов в контексте нет. Сайт не передаёт его в ChatGPT без действия Автора.
4. Автор вставляет контекст в диалог ChatGPT, обсуждает, при необходимости просит внешние исследования, клаузуру/эскиз, переосмысливает идею, выбирает финальную концепцию. Ничего не утверждается автоматически.
5. Если подключённый EGG инструмент `egg_propose_concept` доступен, AI может предложить черновик через проектный API, но не принять его. **На текущий момент подключённый к этому чату EGG v3 предоставляет только get state, contribute, propose seed, register Drive file — отдельная команда `egg_propose_concept` ещё не доступна.**
6. Пока команда недоступна, Автор просит финальный JSON `{"concept":"...","visualUrl":"https://...","questions":[...]}` или обычный текст. Возвращается в исходную сферу по ссылке, вставляет результат в поле импорта и переносит его в редактор. Это **локальный черновик**, до сохранения и утверждения.
7. После явной команды «Передать концепцию на утверждение» создаётся неутверждённая версия в EGG Engine. Действие «Принять концепцию» доступно только Автору, и лишь после принятия можно отправить конкретный вопрос в сферу.
8. В любой из восьми рабочих сфер доступен тот же «Переключиться на ChatGPT» с контекстом этой сферы и действующей концепцией; выводы сохраняются отдельно в `EggSphereWorkspace`.

## Важные границы

- Кнопка **не встраивает чат внутрь EGG**, не переносит автоматически сообщения между двумя сайтами и не продолжает тот же ChatGPT thread без участия пользователя.
- ChatGPT может получить актуальное состояние проекта через EGG только при наличии подключённого приложения/ключа. Если оно недоступно, контекст передаётся вручную.
- Результаты ChatGPT не считаются фактами, доказательствами изготовляемости или авторскими решениями.
- Внешний поиск определяется доступными инструментами AI и разрешениями источников; EGG не вводит заранее закрытый список источников.
- Прототип концепции пока хранит текст и **URL на графику**, но не бинарный файл/изображение. Это предстоит реализовать.
- Технический тест перехода и импорта не равен сквозной проверке в аккаунте реального Автора; пользовательский пилот необходим.

ID `01b3d29f-bfc4-41ed-b31a-2e0db7fa2fe9` — «Лёгкое кресло для отдыха и медитации». Исходная идея существует и доступна из текущего подключённого ChatGPT EGG v3; текущая ревизия при осмотре — 8. В этой ветке нет миграции и не изменены хранимые решения проекта. Только автор может принять новую концепцию.
