# Medeo Sans

Unmodified upstream variable WOFF2 files from [DNFDEVS/medeo-font](https://github.com/DNFDEVS/medeo-font), retrieved 2026-10-29:

- `fonts/MedeoSans/webfonts/MedeoSansVariable.woff2`
- `fonts/MedeoSans/webfonts/MedeoSansVariable-Italic.woff2`

Both files support `wght` 100–900 and `opsz` 14–32, including Russian and Ukrainian Cyrillic. The project-hosted binaries are referenced by the adjacent asset pointers, not Google Fonts or another font provider.

The full upstream copyright notice and SIL Open Font License 1.1 are distributed unchanged at `public/fonts/Medeo-OFL.txt` (served as `/fonts/Medeo-OFL.txt`).
